# Кейс бизнес-аналитика: «Органайзер домашних дел»

## Контекст

Маркетплейс рассматривает запуск нового раздела в мобильном приложении — органайзера домашних дел. Пользователи смогут планировать бытовые задачи, создавать напоминания и заказывать необходимые товары и услуги у партнёров платформы.

Например, пользователь сможет запланировать уборку квартиры, обслуживание кондиционера или доставку воды, а затем перейти к подходящим товарам или услугам. Также пользователь сможет запланировать путешествие и перейти в раздел авиабилетов.

## Цель проекта

Повысить вовлечённость пользователей в экосистему маркетплейса, увеличить частоту использования приложения и расширить количество сценариев взаимодействия с платформой.

## Бизнес-ограничения

На первом этапе продукт не должен приносить прямую выручку. Его ценность заключается в повышении лояльности пользователей и создании дополнительных возможностей для использования других сервисов платформы.
