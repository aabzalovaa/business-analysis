# Функциональные требования

| ID | Название требования | Описание |
|---|---|---|
| FR-001 | Создание задачи | Система должна предоставлять пользователю возможность создать новую задачу и сохранить её. |
| FR-002 | Указание срока выполнения задачи | Система должна предоставлять пользователю возможность указать дату и время выполнения задачи. |
| FR-003 | Выбор категории задачи | Система должна предоставлять пользователю возможность выбрать категорию задачи из предложенного списка. |
| FR-004 | Настройка регулярности задачи | Система должна предоставлять пользователю возможность выбрать регулярность выполнения задачи. |
| FR-005 | Настройка напоминания | Система должна предоставлять пользователю возможность установить напоминание. |
| FR-006 | Просмотр списка задач | Система должна предоставлять пользователю возможность просматривать список созданных задач. |
| FR-007 | Изменение статуса задачи | Система должна предоставлять пользователю возможность изменять статус задачи (например, «новая», «выполнена»). |
| FR-008 | Приоритизация задачи | Система должна предоставлять пользователю возможность установить приоритет задачи (например, высокий, средний, низкий). |
| FR-009 | Управление задачами | Система должна предоставлять пользователю возможность редактировать и удалять созданные задачи. |
| FR-010 | Определение категории задачи | Система должна анализировать выбранную пользователем категорию задачи для формирования релевантных рекомендаций. |
| FR-011 | Формирование рекомендаций после создания задачи | Система должна формировать рекомендации товаров и услуг партнёров платформы после создания пользователем задачи на основе её параметров. |
| FR-012 | Отображение рекомендаций | Система должна отображать пользователю список рекомендованных товаров и услуг с информацией о предложении после успешного создания задачи. |
| FR-013 | Переход к предложению партнера | Система должна предоставлять пользователю возможность перейти к странице товара или услуги партнёра. |
