# Нефункциональные требования

| ID | Категория | Название | Описание |
|---|---|---|---|
| NFR-001 | Производительность | Время отклика | Система должна обеспечивать время отклика на действия пользователя не более 2 секунд при нормальной нагрузке. |
| NFR-002 | Безопасность | Разграничение доступа | Система должна предоставлять доступ к задачам только авторизованному пользователю — владельцу этих задач. |
| NFR-003 | Надёжность | Сохранность данных | Система должна обеспечивать сохранение созданных пользователем задач без потери данных. |
| NFR-004 | Надёжность | Обработка ошибок | При возникновении ошибки система должна отображать пользователю понятное сообщение об ошибке и предоставлять возможность повторить операцию. |
| NFR-005 | Надёжность | Доставка уведомлений | Система должна обеспечивать доставку не менее 99,5% push-напоминаний в пределах ±1 минуты от запланированного времени. |
| NFR-006 | Надёжность | Генерация повторяющихся задач | Система должна корректно создавать повторяющиеся задачи в соответствии с заданной пользователем периодичностью, без пропусков и дублирования. |
| NFR-007 | Удобство использования | Работа без подключения к сети | Система должна обеспечивать возможность просмотра списка задач без подключения к сети. |
| NFR-008 | Совместимость | Поддерживаемые платформы | Система должна корректно работать на актуальных версиях операционных систем iOS и Android. |
| NFR-009 | Масштабируемость | Поддержка роста нагрузки | Архитектура системы должна обеспечивать возможность масштабирования для поддержки роста количества пользователей без изменения бизнес-логики приложения. |
| NFR-010 | Качество данных | Актуальность рекомендаций | Система должна отображать пользователю только актуальные предложения партнёров. |
