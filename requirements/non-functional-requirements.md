# Нефункциональные требования

| ID | Категория | Название | Описание |
|----|-----------|----------|----------|
| NFR-001 | Производительность | Время отклика | Время отклика на действия пользователя не более 2 секунд при нормальной нагрузке. |
| NFR-002 | Безопасность | Разграничение доступа | Доступ к задачам только авторизованному пользователю - владельцу этих задач. |
| NFR-003 | Надежность | Доступность системы | Система должна обеспечивать доступность сервиса не менее 99,5% времени в месяц. |
| NFR-004 | Надежность | Доставка уведомлений | Push-напоминания доставляются в пределах ±1 минуты от запланированного времени. |
| NFR-005 | Удобство использования | Работа без подключения к сети | Доступен просмотр задач без подключения к сети с последующей синхронизацией данных. |
| NFR-006 | Совместимость | Поддерживаемые версии приложения | Функционал органайзера доступен для пользователей с версией мобильного приложения vX.X и выше. |
| NFR-007 | Масштабируемость | Поддержка роста нагрузки | Архитектура системы должна обеспечивать возможность масштабирования при росте количества пользователей. Текущая нагрузка - N пользователей в месяц, прогнозируемый рост в течение года - до 5N пользователей в месяц. |
