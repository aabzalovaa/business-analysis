# UC-001 Создание и настройка задачи

## Название

Создание и настройка задачи.

## Актор

Пользователь.

## Предусловие

- Пользователь зарегистрирован в системе.
- Пользователь находится в разделе «Органайзер домашних дел».

## Основной сценарий

1. Пользователь открывает раздел «Органайзер домашних дел».
2. Пользователь нажимает кнопку «Создать задачу».
3. Пользователь вводит название задачи.
4. Пользователь указывает параметры задачи:
   - название;
   - дату и время выполнения;
   - категорию;
   - приоритет;
   - повтор;
   - настройки напоминания.
5. Пользователь нажимает кнопку «Сохранить».
6. Система проверяет корректность заполнения обязательных полей.
7. Система сохраняет задачу.
8. Система отображает сообщение об успешном создании задачи.

## Альтернативный сценарий

### Альтернативный сценарий 1 — Не заполнены обязательные поля

1. Система определяет, что обязательные поля не заполнены.
2. Система отображает сообщение о необходимости заполнить обязательные поля.
3. Пользователь заполняет необходимые поля.
4. Пользователь нажимает кнопку «Сохранить».
5. Система повторно проверяет данные.
6. Система сохраняет задачу.

## Исключения

### Ошибка при создании задачи

1. При сохранении задачи возникает ошибка системы.
2. Система отображает сообщение об ошибке.
3. Система предлагает повторить попытку позже или обратиться в службу поддержки.

# UC-002 Просмотр списка задач

## Название

Просмотр списка задач.

## Актор

Пользователь.

## Предусловие

- Пользователь зарегистрирован и авторизован в системе.
- У пользователя есть созданные задачи.

## Цель

Просмотр запланированных задач и получение информации о предстоящих делах.

## Основной сценарий

1. Пользователь открывает раздел «Органайзер домашних дел».
2. Система отображает список задач пользователя в календарном формате.
3. Пользователь выбирает период просмотра:
   - день;
   - неделя;
   - месяц.
4. Система отображает задачи за выбранный период.
5. Пользователь открывает карточку задачи.
6. Система отображает подробную информацию о задаче.

## Исключение

1. Система не может загрузить задачи пользователя.
2. Система отображает сообщение об ошибке.

# UC-003 Получение рекомендаций

## Название

Получение рекомендаций.

## Актор

Пользователь.

## Предусловие

- Пользователь зарегистрирован и авторизован в системе.
- Пользователь находится на экране созданной задачи.

## Цель

Пользователь хочет получить подходящие товары и услуги, которые помогут ему выполнить созданную задачу.

## Основной сценарий

1. Пользователь сохраняет задачу.
2. Система сохраняет задачу и анализирует ее параметры (категорию, тип задачи).
3. Система формирует и отображает блок рекомендованных товаров и услуг партнеров.
4. Пользователь выбирает заинтересовавшее предложение.
5. Система открывает карточку товара или услуги.

## Исключения

### Исключение 1 — Ошибка получения рекомендаций

1. Система не может получить данные о товарах и услугах партнеров.
2. Система отображает сообщение о временной недоступности рекомендаций.

### Исключение 2 — Ошибка перехода к предложению партнера

1. Пользователь выбирает предложение партнера.
2. Система пытается открыть страницу товара или услуги.
3. Происходит ошибка перехода.
4. Система отображает сообщение об ошибке.
