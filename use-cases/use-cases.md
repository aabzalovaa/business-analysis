# Use Cases

## UC-001. Создание и настройка задачи

### Название

Создание и настройка задачи.

### Актор

Пользователь.

### Предусловие

- Пользователь зарегистрирован в системе.
- Пользователь находится в разделе «Органайзер домашних дел».

### Цель

Создать задачу и настроить ее параметры.

### Основной сценарий

1. Пользователь открывает раздел «Органайзер домашних дел».
2. Пользователь нажимает кнопку «Создать задачу».
3. Пользователь вводит название задачи.
4. Пользователь указывает параметры задачи:
   - дату и время выполнения;
   - категорию;
   - приоритет;
   - регулярность;
   - настройки напоминания.
5. Пользователь нажимает кнопку «Сохранить».
6. Система проверяет корректность заполнения обязательных полей.
7. Система сохраняет задачу.
8. Система отображает сообщение об успешном создании задачи.
9. Система анализирует параметры задачи и формирует рекомендации товаров и услуг партнёров.
10. Система отображает пользователю рекомендации.

### Альтернативные сценарии

#### Альтернативный сценарий 1 — Не заполнены обязательные поля

1. На шаге 6 основного сценария система обнаруживает, что обязательные поля не заполнены.
2. Система выделяет незаполненные поля.
3. Система отображает сообщение о необходимости заполнить обязательные поля.
4. Пользователь заполняет необходимые поля.
5. Система повторно проверяет данные.
6. Если проверка пройдена успешно, сценарий продолжается с шага 7 основного сценария.

#### Альтернативный сценарий 2 — Не удалось загрузить рекомендации

1. Задача успешно сохраняется.
2. Система не может получить или сформировать рекомендации.
3. Система отображает сообщение о временной недоступности рекомендаций.
4. Созданная задача остаётся доступна пользователю.

### Исключения

#### Исключение 1 — Ошибка сохранения задачи

1. При сохранении задачи возникает системная ошибка.
2. Система отображает сообщение об ошибке.
3. Система сообщает пользователю, что задача не была сохранена, и предлагает повторить операцию позже.

## UC-002. Управление задачами

### Название

Управление задачами.

### Актор

Пользователь.

### Предусловие

- Пользователь зарегистрирован и авторизован в системе.
- Пользователь находится в разделе «Органайзер домашних дел».
- У пользователя есть хотя бы одна созданная задача.

### Цель

Просматривать созданные задачи и управлять ими: изменять параметры и статус, а также удалять ненужные задачи.

### Основной сценарий

1. Пользователь открывает раздел «Органайзер домашних дел».
2. Система отображает список созданных задач пользователя.
3. Пользователь выбирает необходимую задачу.
4. Система отображает подробную информацию о выбранной задаче.
5. Пользователь выбирает действие для управления задачей.
6. Система выполняет выбранное действие согласно соответствующему альтернативному сценарию.

### Альтернативные сценарии

#### Альтернативный сценарий 1 — Редактирование задачи

1. Пользователь выбирает действие «Редактировать задачу».
2. Система открывает форму редактирования задачи.
3. Пользователь изменяет необходимые параметры:
   - название;
   - дату и время выполнения;
   - категорию;
   - приоритет;
   - регулярность;
   - настройки напоминания.
4. Пользователь сохраняет изменения.
5. Система проверяет корректность введённых данных.
6. Система сохраняет обновлённую информацию.
7. Система отображает пользователю обновлённую задачу.

#### Альтернативный сценарий 2 — Изменение статуса задачи

1. Пользователь выбирает действие «Изменить статус».
2. Система отображает доступные статусы задачи.
3. Пользователь выбирает новый статус:
   - новая;
   - в процессе выполнения;
   - выполнена;
   - отменена.
4. Система обновляет статус задачи.
5. Система отображает обновлённый статус.

#### Альтернативный сценарий 3 — Удаление задачи

1. Пользователь выбирает действие «Удалить задачу».
2. Система отображает окно подтверждения удаления.
3. Пользователь подтверждает удаление.
4. Система удаляет задачу.
5. Система обновляет список задач.

### Исключения

#### Исключение 1 — Ошибка сохранения изменений

1. Система не может сохранить изменения.
2. Система отображает сообщение об ошибке.
3. Предыдущая версия задачи остаётся без изменений.
4. Пользователь может повторить попытку позже.

#### Исключение 2 — Задача недоступна

1. Пользователь выбирает задачу.
2. Система не может найти выбранную задачу.
3. Система отображает сообщение о недоступности задачи.
4. Система возвращает пользователя к списку задач.

## UC-003. Взаимодействие с рекомендациями

### Название

Взаимодействие с рекомендациями товаров и услуг партнёров.

### Актор

Пользователь.

### Предусловие

- Пользователь зарегистрирован и авторизован в системе.
- У пользователя есть созданная задача.
- После создания задачи система сформировала и отобразила рекомендации на основе её параметров.

### Цель

Ознакомиться с рекомендованными товарами и услугами партнёров и перейти к подходящему предложению для решения своей задачи.

### Основной сценарий

1. Пользователь просматривает блок рекомендаций, отображённый после создания задачи.
2. Система показывает список рекомендованных товаров и услуг партнёров.
3. Пользователь выбирает заинтересовавшее предложение.
4. Система отображает информацию о выбранном предложении.
5. Пользователь переходит на страницу товара или услуги партнёра.

### Альтернативные сценарии

#### Альтернативный сценарий 1 — Пользователь просматривает дополнительные предложения

1. Пользователь выбирает действие «Показать больше предложений».
2. Система получает дополнительные предложения партнёров.
3. Система отображает обновлённый список рекомендаций.
4. Пользователь выбирает подходящее предложение.

#### Альтернативный сценарий 2 — Пользователь сохраняет рекомендацию

1. Пользователь выбирает действие «Добавить в избранное».
2. Система сохраняет выбранное предложение.
3. Система отображает подтверждение сохранения.

### Исключения

#### Исключение 1 — Ошибка получения рекомендаций

1. Система не может получить данные о товарах и услугах партнёров.
2. Система отображает сообщение о временной недоступности рекомендаций.
3. Система предлагает повторить попытку позже.

#### Исключение 2 — Ошибка перехода к предложению партнёра

1. Пользователь выбирает предложение партнёра.
2. Система пытается открыть страницу товара или услуги.
3. Возникает ошибка перехода.
4. Система отображает сообщение об ошибке.
5. Пользователь может повторить попытку позже.
