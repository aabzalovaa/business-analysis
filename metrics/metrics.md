# Метрики

## Цель

Повысить вовлеченность пользователей в экосистему Wildberries, увеличить частоту использования мобильного приложения и расширить число пользовательских сценариев взаимодействия с сервисами маркетплейса.

## North Star Metric

**North Star для органайзера** — количество пользователей, которые за неделю перешли хотя бы в один сервис экосистемы из органайзера.

Метрика отражает основную цель продукта — вовлечение пользователей в экосистему Wildberries и расширение сценариев взаимодействия с сервисами платформы.

---

## Метрики-ограничители (Guardrails)

- Доля пользователей, отключивших push-уведомления.
- Рост числа удалений приложения.
- Количество жалоб на навязчивость рекомендаций.

# Количественные метрики

## На уровне продукта

| Метрика | Что показывает | Как считать? |
|---------|----------------|--------------|
| Охват | Сколько пользователей попробовали фичу? | Пользователи, открывшие раздел / Все пользователи маркетплейса |
| Количество пользователей, создавших хотя бы одну задачу | Дошел ли пользователь до первой ценности | Пользователи, создавшие первую задачу / Пользователи, открывшие раздел |
| Количество задач на пользователя | Глубина использования | Созданные задачи / Активные пользователи органайзера |
| Доля повторяющихся задач | Формируется ли привычка | Задачи с регулярностью / Все задачи |
| WAU / MAU органайзера | Популярность фичи | Уникальные пользователи за неделю и месяц |
| Stickiness | Стал ли продукт частью привычки пользователя | DAU / MAU × 100% |
| Retention (7 дней / 30 дней) | Возвращаются ли пользователи | Доля вернувшихся через 7 и 30 дней после первого использования |
| Доля завершенных задач | Полезность на практике | Задачи в статусе «Выполнена» / Все задачи со сроком в периоде |

---

## На уровне экосистемы

| **Метрика** | **Что показывает** | **Как считать?** |
|-------------|--------------------|------------------|
| Количество сессий приложения (с органайзером и без) | Повысилась ли вовлеченность пользователей в приложение | Среднее количество сессий на пользователя в неделю (у пользователей с органайзером и без него) |
| CTR блока рекомендаций | Интерес к предложениям | Клики по рекомендациям / Показы блока рекомендаций |
| Количество заказов на пользователя | Рост вовлеченности в покупки | Число заказов на пользователя за период у групп с фичей и без |
| Средний чек пользователей с органайзером и без | Увеличился ли средний размер покупки | Средний чек пользователей с органайзером и без него за одинаковый период |
| Доля заказов из органайзера | Вклад органайзера в общий объем заказов платформы | Заказы, оформленные после перехода из органайзера / Все заказы платформы |

# Качественные метрики

| Метрика | Что дает? | Как собирать? |
|---------|-----------|---------------|
| NPS | Готовность рекомендовать | Опрос: «Порекомендуете ли вы органайзер друзьям?» (0–10) |
| CSAT | Удовлетворенность продуктом | Опрос: «Оцените органайзер от 1 до 5?» |
| Оценка рекомендаций | Релевантность предложений | Кнопки «Полезно / Не полезно» под рекомендацией |
| Юзабилити-тестирование | Где пользователи «спотыкаются» | Наблюдение за прохождением сценариев из **[Use Cases](../use-cases/use-cases.md)** |
| Отзывы и обращения в поддержку | Типичные проблемы | Анализ отзывов |
